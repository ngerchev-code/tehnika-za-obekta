# Техника за обекта — Android приложение

CRM за търговец на строителна и комунална техника (Екосол България): клиенти, каталог техника, оферти, календар с напомняния, седмични отчети по Excel шаблон. Работи без интернет; данните са само на телефона.

## Как се получава APK (без компютърни програми)

1. Влезте в **github.com** (същия акаунт като за другите приложения).
2. Създайте ново хранилище: **New repository** → име `tehnika-za-obekta` → изберете **Private** → **Create**.
3. В празното хранилище натиснете **uploading an existing file** и пуснете всички файлове и папки от архива (без папка `node_modules`, ако се появи). Натиснете **Commit changes**.
   - Папката `.github` е скрита в някои телефони/компютри — тя е задължителна, без нея няма автоматична компилация.
4. Отворете раздел **Actions** → „Компилиране на APK“ трябва да тръгне сам (ако не — **Run workflow**). Отнема ~5–8 минути.
5. Готовото APK е в **Releases** (вдясно на началната страница) → `Tehnika-za-obekta-v1.0.N.apk`. Свалете го на телефона и го отворете → разрешете „инсталиране от този източник“.

Всяко следващо качване на промени прави нова версия, която се инсталира **върху** старата, без да губи данни (ключът за подпис `android/app/tehnika-release.jks` е в проекта — дръжте хранилището **Private**).

## Първи стъпки в приложението

- **⋮ → Настройки и архив → Импорт на клиенти от Excel** — изберете вашата база, посочете колоните. Дубликати по ЕИК/име се пропускат.
- **⋮ → Седмични отчети → Зареди шаблон** — вашият оригинален .xlsx. Колоните и оформлението идват от него.
- **Техника** — марките са създадени; моделите, параметрите (с източник и дата) и снимките (първата = основна, на бял фон) се въвеждат от официални документи.
- **Настройки → Известия → Тестово известие** — затворете приложението и проверете дали звъни.
- **Архив** — правете редовно; възстановяването само добавя/обновява, не трие.

## Какво още не е свързано (нужен е избран източник/API)

- Трафик с червен банер и звук; тематични новини; обществени поръчки като поток; злато, петрол, литий; статистики за бранша.
- Време: работи с ваш AccuWeather API ключ (Настройки). Безплатният план има малко заявки на ден — на 15 минути е нужен платен план.
- EUR/USD: референтен курс на ЕЦБ (без ключ).
- Офертата се споделя като HTML документ (отваря се в Chrome → Печат → PDF). За Word/PDF по вашия оригинален шаблон е нужен шаблонът.
- Данните от ChatGPT версията не са пренесени — нужен е експорт от там.

## Техническо

Capacitor 8 (Android WebView), IndexedDB, Local Notifications (точни аларми, работят и при затворено приложение и след рестарт), SheetJS (импорт), ExcelJS (отчет по шаблон). `www/` е кодът на приложението; `npx cap sync android` го копира в Android проекта.
